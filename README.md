# Jangu Creative Tech & Multimedia — Portfolio Website

A responsive, animated agency portfolio built from scratch using HTML, CSS and JavaScript.

## Brand
The site uses the colors sampled from the supplied Jangu logo:
- Deep Navy / Black: #0B1022
- Electric Blue: #08A9F5
- Deep Blue: #0064E8
- Orange: #FF6A00
- Warm Orange: #FF9B00

## Files
- index.html — complete website structure
- styles.css — responsive visual design and animations
- script.js — cursor glow, reveal animations, mobile navigation and interactive project brief selector
- assets/jangu-tech-logo.png — supplied Jangu logo

## Run
No build tools are required.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For development in VS Code, you can use the Live Server extension.

## Customize
Replace the placeholder project visuals with your real project screenshots.
Update:
- Email address in `index.html`
- GitHub / LinkedIn / Instagram links
- Project names and descriptions
- About text
- Service details
